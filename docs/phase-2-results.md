## Implemented functionality

- Exact approved assignment v1/v2 validation and normalization, with original
  required/optional fields, strict unknown-field rejection, ordering, supported
  YouTube/Forms URL patterns, filename/ID checks and original diagnostics.
- S01–S12 selection from a **version-1 manifest allowlist**. No probing of
  unpublished filenames, paths or remote URLs. The default public manifest is
  empty; the original synthetic five-question Demo Mode remains usable.
- An **Assignments** HUD button, native selector dialog, published-list refresh,
  explicit replacement confirmation, and cancel/Close/Escape. A whole new unit
  must download and validate before activation. Abort and generation checks
  suppress stale response/body results. Failed/canceled requests preserve the
  current unit, passes and player location; a failed refresh revokes only its
  obsolete allowlist. Confirmed successful replacement resets question progress.
- Real question title/prompt/options rendered as text in the existing quiz.
  One selected radio maps to A–D. V1 accepts `correctOption`; v2 accepts any one
  member of `correctOptions`. Three-option questions have no D. Wrong answers
  permit immediate retry and never revoke earlier passes.
- Q01–Q05 map directly to the unchanged fixed terminal coordinates. A
  four-question unit hides Q05, excludes it from X/proximity interaction and
  removes only its casing from the shared collider array. A five-question unit
  restores Q05 at the same site. Completion is 4/4 or 5/5 accordingly.
- The Phase 1 native-dialog isolation was extracted into `createModalBarrier`
  and reused for both dialogs: top layer, explicit inert background, dynamic UI
  isolation, event barrier, input suspension/held-key clearing, focus trap and
  restoration, Close/Escape and explicit click to reacquire Pointer Lock.
- Progress and active-unit state are **in memory only**. Reload/reopen starts
  fresh Demo Mode at 0/5; no assignment state is written to localStorage,
  sessionStorage or a backend. No identity/answer collection or analytics.

The teacher GUI and export contracts are unchanged. URL fields are validated
but no video, explanation-video or Form actions are exposed. No autoplay,
embeds, playback checks or tracking were implemented. `Plan.md` now records
session-only progress and the future explicit-new-tab Phase 3 behavior.

## Reproduce

Follow the established cloud install/HTTPS setup. With the pinned Node on PATH:

```bash
npm ci
npm test
npm run build
python -m unittest tests.test_assignment_contract -v
BROWSER=none npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

In a second shell, extract the dev server's public certificate as in Phase 0 and run:

```bash
python scripts/browser-phase-1.py --cafile /path/to/vite-local.crt
python scripts/browser-phase-2.py --cafile /path/to/vite-local.crt
python scripts/verify-baseline.py --origin https://127.0.0.1:5173 --cafile /path/to/vite-local.crt
```

The production preview was started fresh on **4174** (an older preview already
occupied 4173). Its own current public certificate was exported and used with
normal TLS verification. `npm ci` removes generated certificates, so restart or
export the certificate for the specific server being tested; do not trust a
stale certificate or disable TLS verification. See
[assignment-integration.md](assignment-integration.md) for optional Python/browser
prerequisites, default paths and read-only export validation.

Perform in both browsers on supported physical WebGPU hardware, using
instructor-controlled local acceptance exports or intercepted test fixtures.
No synthetic fixture is authorized for publication to a production assignment
directory. Record browser/GPU and failure steps; these boxes remain unchecked.

- [ ] Original city/effects start normally. Walking remains 4.5 m/s, Shift tops
  out at 9 m/s, and mouse stability, R/P, Pointer Lock, collision and crouch work.
- [ ] With the default empty manifest, Demo Mode is clearly identified and all
  five original questions work. A failed list refresh does not break it.
- [ ] Release mouse with Escape, open Assignments, and refresh the list. Only
  published S01–S12 entries appear. Close/Escape restore focus and require a
  new click for Pointer Lock, without stuck keys or background clicks.
- [ ] Select Load unit: no replacement occurs before confirmation. Cancel,
  including while a download is pending, preserves unit/progress/location.
- [ ] Load valid v1 four/five and v2 three/four-choice exports. Title, prompt,
  Unicode and option order match the GUI export; exactly one radio is selected.
  No fabricated D or schema migration occurs. No video/Form actions appear.
- [ ] Verify 4/4 and 5/5 completion. Q05 is hidden/inactive for four questions,
  restored at the original position for five, and can be opened only nearby.
- [ ] Wrong answers immediately permit retry. A v2 accepted alternative passes;
  revisiting a completed question never revokes its pass. Other passes remain.
- [ ] Successful replacement resets only progress; camera/player location stays
  put. Restarting the same unit requires confirmation and starts at zero.
- [ ] Offline/HTTP/malformed/invalid export failures show useful errors and keep
  active progress. Refreshing to an empty list also keeps an active valid unit.
  Rapid refresh/selection/cancel does not allow stale content to activate.
- [ ] While either dialog is open, clicks over underlying Settings/About/Source,
  canvas and Controls do nothing; WASD/R/P/X are isolated. Tab/Shift+Tab remain

## Known limitations and stop

Phase 2 was subsequently accepted by the instructor and merged through PR #4.
The historical automated checks did not themselves establish physical GPU acceptance. Real
coursework and provider navigation were not tested; only unpublished synthetic
fixtures were used. Assignment paths follow the document subdirectory, but
upstream absolute city/model/media paths still require separate release work
for an entire Apache subdirectory site. Session-only progress is intentional.

All original [asset licensing warnings](asset-licenses.md) remain unresolved,
including the five GLBs' insufficient redistribution evidence. This phase
does not clear assets for public release or deployment. The Phase 2 Draft PR
stop was completed by acceptance/merge; Phase 3 now has separate authorization.
